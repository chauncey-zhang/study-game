# 🎓 知识大冒险 —— 学习闯关游戏

一个**纯静态、零依赖、零编译**的小学一年级到初三（人教版）全科学习闯关游戏。
双击 `index.html` 即可在浏览器中运行，支持 **手机 / 平板 / 电脑 / 智能电视（含小米电视，遥控器操作）**。

> 🎯 设计目标：让孩子在"打游戏"的过程中完成全科知识的学习与巩固。
> 游戏化外壳（关卡地图 / 打怪 / 宠物 / 成就）+ 学习内核（2.3 万题全科题库）。

## 二、核心玩法流程

```
选择年级（1-9） → 选择科目 → 🗺️ 冒险地图 → 选择玩法模式 → 战斗/练习 → 结算（经验/星星/宠物蛋）→ 解锁下一关
```

### 2.1 选择年级

首页顶部一排年级按钮（一年级 ~ 九年级）。每个年级自动只显示该年级**实际开设的科目**：

- 1~6 年级：语文、数学、英语
- 7 年级：+生物、地理、历史、道德与法治
- 8 年级：+物理
- 9 年级：+化学

### 2.2 选择科目 → 冒险地图

点击学科卡片进入该科该年级的**冒险地图**：

- 每关 **5 题**，关卡按题库顺序固定划分（内容稳定，可反复挑战刷星）
- **逐关解锁**：通过上一关（≥1 星）才能解锁下一关
- 👑 **每关最后一题是 Boss 战**：怪物变大变红，答对额外 +10 经验
- 已通关的关卡显示获得星级（⭐~⭐⭐⭐），下一个待打关卡会跳动提示
- 题目多的学科（如数学 ~190 关）自动**分页**显示，底部 ◀ ▶ 翻页

### 2.3 五种玩法模式（关卡地图顶部切换）

| 模式 | 玩法 | 走关卡星级 | 可用学科 |
|------|------|-----------|---------|
| ⚔️ 闯关选择 | 经典四选一，答对攻击怪物 | ✅ | 全科 |
| ⚖️ 判对错 | 显示题目和一个"说法"（50% 是错的），判断对错；**5 秒内答对有 ⚡手速加成** | ✅ | 全科 |
| 🃏 闪卡记忆 | 显示题目→心里想答案→点"翻开"核对→自评"😊我会了 / 🤔还不会"；不会的自动进错题本 | ❌（10 张一局） | 全科 |
| 🔢 口算输入 | **没有选项**！弹数字键盘直接输入答案（支持 ⌫/C/±/小数点） | ❌（10 题一局） | 数学、物理 |
| 🔤 单词拼写 | 显示中文，用 26 字母键盘拼出英文（大小写不敏感） | ❌（10 词一局） | 英语 |

> 💡 闪卡 / 口算 / 拼写是"自由练习"：给经验、掉宠物蛋、错题入本，但**不刷关卡星级**（防止刷星破坏闯关成就感）。
> 💡 低年级（1~2 年级）开启**自动读题**：题目出现后自动语音朗读（口算/拼写模式只读题干，避免泄题）。

### 2.4 战斗机制

- 玩家 **3 条命 ❤️❤️❤️**：答错扣 1 命，命尽提前结束
- **怪物血条 = 本关题数**：答对 1 题扣怪 1 血
- **连击**：连续答对经验递增（+10、+11、+12...），连击 ≥2 显示 🔥 徽章
- **必杀技**：连击达到 3 触发——全屏金色"⚡ 必杀技！" + 爆炸粒子 + 金色"暴击！"伤害数字
- 每次答对：英雄🦸出招冲刺动画、怪物受击抖动、红色 `-1` 伤害数字、星星粒子、绿色闪光
- 答错：红色闪光 + 屏幕震动 + 英雄掉血 `-1❤`，出战宠物摇头安慰

### 2.5 专项训练 🚀（口算特训 / 单词特训 / 思维素养）

首页底部的专项入口，与普通闯关并行，共用战斗引擎、成就系统和食物奖励：

**🧮 口算特训（数学）**
- 一键生成本年级指定数量的口算（10 / 20 / 30 / 50 题可选），数字键盘作答，3 条命照常
- **逐题计时**：结算页显示每题耗时（绿色=答对/红色=答错）、总耗时、平均每题耗时、正确率
- **每日打卡与对比**：每天首次完成自动打卡（连续天数累计），结算自动对比昨天的平均速度（快了/慢了几秒）；配置页展示最近 7 天趋势条
- 相关成就：口算新秀（首次完成）、快算达人（平均 ≤6 秒/题）、七日打卡（累计 7 天）

**🔤 单词特训（英语）**
- 年级累计词库（~970 词）随机抽词闯关，26 字母键盘拼写，词量 10 / 20 可选（也支持自定义数量，≥5 不限制上限，可一次性刷完整个词库）
- **错词复习**：拼错的词自动进入待复习队列（按最久未练优先），一键复习；同一单词连续拼对 2 次且从未拼错 → 标记为熟词
- 配置页实时统计：词库总词数 / 已练 / 熟词 / 待复习
- 相关成就：拼词高手（累计拼对 50 词）、复习达人（复习 30 词次）、单词满分（一局全对）

**📚 词库顺序闯关（人教版 3~9 年级）**
- 按人教版教材顺序，3~9 年级共 722 词，每关 10 词、逐关解锁，星级结算（全对 3 星）

### 3.4 宠物系统 🐾

**掉蛋**：通关即有概率掉宠物蛋——1 星 40% / 2 星 70% / **3 星必掉**；掉落时有粒子特效 + 提示，顶部 🐾 按钮变成 `🥚×N`。

**孵化**：宠物乐园点"✨ 孵化"→ 蛋左右摇摆 0.9 秒 → 孵出宠物：

### 6.3 如何追加题目

编辑对应 `data/*.js`，往数组里加一条：

{ q: '题干', o: ['选项A','选项B','选项C','选项D'], a: 0, e: '解析', g: [适用年级] }

## 八、常见问题 FAQ

**Q1：双击打开后没有声音/语音？**
浏览器要求首次交互后才能播放音频/语音——点一下屏幕任意位置即可。部分老电视浏览器不支持 TTS，会自动静默降级。

**Q2：英语拼写模式在电视上不方便？**
是的，拼写需要输入。电视上建议用闯关/判对错/闪卡模式；拼写更适合手机/电脑。

**Q3：换了电脑/浏览器，进度没了？**
用原设备"用户中心 → 📤 生成备份码"，新设备"📥 导入备份码"即可完整恢复。

**Q4：题目会不会重复出现？**
手写题固定；生成题每次刷新页面重新生成，同一关卡每次题目都不同（防背题）。关卡内题目顺序固定，但选项位置每次洗牌。

**Q5：如何给孩子加题？**
编辑 `data/` 下对应学科 js 文件追加题目（格式见 6.3），或在 `generated.js` 的词表/诗句表中追加条目。

**Q6：宠物会消失吗？**
不会，宠物和蛋都存在存档里，且绑定用户档案。

**Q7：能同时给多个孩子用吗？**
可以，注册不同用户名即可，各档案完全隔离，登录切换。

## 九、技术要点

- **零依赖**：无框架、无构建、无外部 CDN，全部原生 HTML/CSS/JS（ES5 语法，兼容老电视内核）
- **音效**：Web Audio API 实时合成（振荡器 + 包络），无音频文件
- **语音**：Web Speech API（speechSynthesis），系统自带中文语音
- **动画**：CSS3 keyframes + JS 粒子系统（伤害数字/星星爆裂/全屏闪光/屏幕震动/必杀技）
- **焦点导航**：几何最近邻算法实现 2D 方向键导航（适配任意网格布局）
- **存储**：localStorage 多用户档案 + 实时写回 + 备份码（Base64）/备份文件双向迁移
- **Hash 路由**：`#/map/数学/g3` 式 URL 标识当前界面（首页/地图/战斗/口算/拼写/闪卡/错题重练/专项配置与挑战），刷新后自动恢复所在页面（战斗重打当前关），浏览器/遥控器返回键可逐级回退
- **生成器**：规则引擎保证答案正确（计算题程序算、词表/诗句/化学式表驱动），加载时生成 ~2.3 万题仅约 0.4 秒
